# 《逆命录》最小可玩版本

这是 [全员 Agent 修仙沙盒项目分享文档](../docs/全员Agent修仙沙盒-项目分享文档.md) 中“地下坊市的一场机缘”的独立玩法切片。使用原创人物与世界观，不依赖仓库中的其他游戏代码。

## 启动

需要 Node.js 22 或更新版本。无需安装依赖：

```bash
cd mvp
npm start
```

在浏览器打开 `http://127.0.0.1:4177`。服务只监听本机。退出服务用 `Ctrl+C`。存档自动保存在 `mvp/.data/save.json`；游戏界面的“重开此局”会覆盖此存档。

## 试玩目标

一枚筑基丹由丹商沈秋持有，开价 280 灵石。你拥有 180 灵石、1 株灵草和 1 张天雷符，每旬有 3 次行动。观察 8 名人物的公开动向，夺得筑基丹，并查看事件账中各行动的缘起。

可以尝试这些路线：

1. **交易：**请白芷验丹 → 找徐宁合资 → 卖出灵草 → 推进一旬 → 买丹。徐宁的合资承诺仍须履行；可以入林采药再卖出补足灵石。
2. **举报：**从宁素取得货道证词 → 向陆执事举报 → 推进一旬 → 以 150 灵石从公售中买丹。
3. **伏击：**约沈秋在黑风林验货 → 入林 → 布下天雷符 → 推进一旬 → 伏击。会损失气血和声望，之后还会被追查。
4. **观察蝴蝶效应：**向青闻买空白鉴定印 → 伪造有毒鉴定 → 连续推进两旬。看宁素、白芷、沈秋、徐宁和青闻如何接力行动。

界面的自然语言框一次只执行**一个**行动，例如“请白芷验丹”“我想找徐宁合资”，或“我拿货道证词压价，出价 200 灵石买丹”。最后一种会按你掌握的证据、实际灵石和沈秋的底价结算；这是一条按钮之外的议价路线。按钮和自然语言共用同一套规则；输入“我立刻得到一亿灵石”不会改写资源。点击人物可交谈，点击事件中的“缘起”可查看此前事件。

## Agent 与模型的边界

默认的离线模式已经可完整试玩。8 名人物都有目标、地点和自己掌握的线索；推进时间时，人物根据这些状态和目前设计好的行动规则作出反应。规则层决定物品归属、钱、气血和后果，因此离线模式能够稳定复盘。人物策略目前是有限的条件决策，尚不是能自主规划任意长期目标的通用 Agent。

如果要让模型解析更自由的中文行动，可配置兼容 OpenAI Chat Completions 的服务。**模型只负责把输入映射到候选行动 ID 和有限参数；服务器仍会校验位置、证据和资源。**当前版本不使用模型生成 NPC 对话或决定世界事实，也不承诺任意自然语言计策都能执行。

```bash
LLM_BASE_URL=http://127.0.0.1:11434/v1 \
LLM_MODEL=你的模型名 \
npm start
```

云端服务还需设置 `LLM_API_KEY`。密钥只从启动服务的环境变量读取，不会传给浏览器。模型超时或返回无效行动时，自动回退到本地中文指令解析。请勿在公开网络上开放此本地服务。

## 验证

```bash
cd mvp
npm test
```

测试覆盖交易并履约、举报查封、伏击代价、假消息传播以及非法行动不改写状态。服务提供 `/api/state`、`/api/action`、`/api/command`、`/api/advance`、`/api/reset`，供浏览器界面使用。

## 本版边界

这是单机、单存档的试玩切片。世界只包含两处地点、一枚筑基丹和 8 名关键人物；没有大地图、完整回合斗法、夺舍、魂幡或可无限扩展的自然语言行动。人物的可见诉求与隐含目标分开保存，事件账记录角色行动与因果；下一阶段可根据盲测结果扩展人物策略、交易品类和模型参与度。
