# 《逆命录》地图版 MVP

这是 [全员 Agent 修仙沙盒项目分享文档](../docs/全员Agent修仙沙盒-项目分享文档.md) 中“地下坊市的一场机缘”的独立试玩切片。主界面是一张可探索的 3D 地图，包含地下坊市、黑风林、玩家模型和 8 名人物模型。场景及人物由 Three.js 几何体原创搭建，不使用仓库其他页面或 Unity 项目的资产。

## 启动

需要 Node.js 22 或更新版本，以及支持 WebGL 的浏览器。

```bash
cd mvp
npm ci
npm start
```

打开 `http://127.0.0.1:4177`。默认使用离线规则解析，完整玩法可运行。服务仅监听本机地址。存档位于 `mvp/.data/save.json`；“行囊 → 重开此局”可开始新局。当前只有一个共享存档，请只在一个标签页游玩。

要使用本机 Ollama 模型，先确认 `ollama list` 中有 `qwen2.5-coder:14b`，启动 Ollama 服务，然后运行：

```bash
cd mvp
npm run start:ollama
```

如果使用其他兼容 OpenAI Chat Completions 的模型服务，可自行设置 `LLM_BASE_URL`、`LLM_MODEL`，云端服务还可设置 `LLM_API_KEY`。例如：

```bash
LLM_BASE_URL=http://127.0.0.1:11434/v1 LLM_MODEL=qwen2.5:0.5b npm start
```

模型响应默认最多等待 30 秒，可用 `LLM_TIMEOUT_MS` 调整。明确的中文行动先由规则解析器处理；它无法识别的表达再交给模型映射到游戏行动。模型超时或返回无效内容时会回退到规则解析，并在成功执行时提示回退。模型只解析行动，不能自行改写灵石、物品或战斗结果。

## 地图操作

- 点击道路和空地寻路，或用 WASD / 方向键移动；建筑、摊位、树木和岩石会阻挡通行。滚轮缩放。
- 点击人物模型，角色会走近，随后可交谈或选择与此人相关的行动。
- 在黑风林点击“灵草坡”采药，点击“天雷阵位”布阵或伏击。所有关键行动都有地图入口；左侧“行动”浮层也可快速选择。
- 点击界门或门另一侧的道路可在坊市与黑风林之间移动；跨区域消耗 1 次行动。
- 地图左侧的“机缘、行囊、人物、行动、邸报”会打开浮层；再次点击或按 Esc 关闭。地图始终是主画面。
- 地图底部可写自然语言计策，一次输入对应一个行动。例如“请白芷看看这颗丹是不是掺了东西”或“我拿货道证词压价，出价 200 灵石买丹”。Enter 执行，Shift+Enter 换行。
- 每旬有 3 次行动；右上角“推进一旬”会结算人物行动和事件。

## 试玩目标

沈秋持有一枚筑基丹，开价 280 灵石。你初始有 180 灵石、1 株灵草和 1 张天雷符。可尝试：

1. **交易：**请白芷验丹 → 找徐宁合资 → 卖灵草 → 推进一旬 → 买丹。合资承诺仍须履行。
2. **举报：**找宁素取得货道证词 → 向陆执事举报 → 推进一旬 → 从公售中买丹。
3. **伏击：**约沈秋出城 → 穿过界门入林 → 布下天雷符 → 推进一旬 → 伏击。会付出气血和声望代价。
4. **传闻：**向青闻买空白鉴定印 → 伪造有毒鉴定 → 推进时间，观察人物的连锁反应。

“邸报”记录事件及其缘起。当前人物策略是有状态的条件决策，行动范围由规则引擎限定；这还不是能自主规划任意目标的通用 Agent。地图只包含两处区域，人物模型采用简洁低多边形风格，尚无完整斗法、夺舍或魂幡系统。

## 验证

```bash
cd mvp
npm test
```

规则测试覆盖交易履约、举报查封、伏击代价、假消息传播及非法行动。服务提供 `/api/state`、`/api/action`、`/api/command`、`/api/advance`、`/api/reset` 给本地页面使用。
