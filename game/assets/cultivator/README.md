# 装备页人物立绘

`portrait.png` 是人物底图，`spirit-bottle.png` 是小绿瓶的透明叠加层，两者均为 600 × 1567。由 `equipment-art.js` 以相同位置和尺寸展示，小绿瓶仅在存档中已经认主时显示；兵器由独立 SVG 图层按真实装备显示。

素材取自本仓库现有的 `assets/generated/hanli-cutout.png`，裁去空白并保留原面部、束发、衣料和手部细节。仅将蓝色外袍调为青绿色、收紧透明边缘，并从底图中移除小绿瓶，制成独立图层。原始素材未修改。本次没有调用图像生成 API。

人物服饰与装饰只用于表现，不提供额外装备或属性。更新图片时须保持两层尺寸、裁切范围和人物位置一致，避免法宝错位或在未获得时显示。
