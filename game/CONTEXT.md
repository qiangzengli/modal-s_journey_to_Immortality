# 凡人修仙传游戏领域词汇

以韩立的修行经历为主线，人物与修仙世界沿用《凡人修仙传》的设定。

## 故事与人物

**主线**：从七玄门、神手谷、嘉元城、太南小会进入黄枫谷，再经百药园修炼、血色禁地采药、筑基拜师的修行经历。

**自由分支**：玩家与人物依据当前资源和关系作出的交易、委托、问计与斗法选择，并非原著中的既定事件。

**剧情经历**：由玩家亲自完成的故事行动；人物的建议或承诺不等于已经发生。

**经历取舍**：玩家在具体处境中确认的做法；主线结果固定，选项的耗时和信任收益由规则结算，相关人物保留记忆。

**潜修**：一次确认后结算若干游戏旬数，灵圃和既有约定正常推进，不设置现实等待。

**旧历衔接**：旧档已经越过的新增经历，只视为前置已满足，不补发资源或虚构选择记忆。

**剧情信物**：遗书、暖阳宝玉、升仙令、丹方等与主线相关的凭据。

**任务药囊**：血色禁地采得的紫猴花、玉髓芝与天灵果，作为自行留种培育的活株，不与普通灵草混同。

**筑基丹**：辅助炼气修士突破筑基的丹药，须将紫猴花、玉髓芝、天灵果留种培育，成熟采收后按丹方亲手炼制，不能直接购买、议价、夺丹或交药领取成丹。旧存档已持有的丹药仍可服用，不重复补发。
_Avoid_：归脉丹

**筑基药畦**：百药园中玩家自己的三味主药活株，生长满四点才能采收；每旬自然增长一点，开启自动浇灌时优先消耗一滴灵液再增加一点。成熟主药只够本批炼制一枚筑基丹。

## 修行与门派

**修为境界**：凡人之后依次为炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘，再渡劫飞升。炼气分十三层；筑基至合体各有初期、中期、后期。

**越国七派**：黄枫谷、掩月宗、清虚门、灵兽山、巨剑门、天阙堡、化刀坞。

**魔道六宗**：合欢宗、鬼灵门、魔焰门、御灵宗、血杀宗、千幻宗。

**门籍**：修士的宗门归属，同一修士同时只有一份门籍。

**接引**：门人审阅拜帖后的邀请；申请人接受才正式入门。升仙令另为黄枫谷认可的入门凭据。

**拜师**：筑基后的韩立拜入李化元门下，与此前登记黄枫谷门籍是不同的经历。

## 游历与交互

**区域**：独立的地图空间，须符合修为或故事条件才可进入。

**地点**：区域内的可交互位置，玩家抵达后明确选择行动。

**委托**：人物提出的灵草交换，报酬由委托人预存；实际交付后才能领取。

**人物能力**：人物依据自身资产、已知事实和关系能够采取的行动。

**基础攻击力**：不计装备与招式加成的攻击属性。

**基础法力**：法术伤害与治疗的强度，不是施法时消耗的资源。

**真气**：斗法中消耗与恢复的施法资源。

**剧情斗法**：主线或支线中的真实回合对阵；胜利和收取战利品是两个结算阶段。逃跑与战败不完成经历。

**银色书页**：从巨剑门赤脚大汉的储物袋取得的剧情信物，可在出禁地、筑基拜师后继续研究。

**室内空间**：建筑门槛以内可进入、走动和交互的空间，与所属区域相连。
