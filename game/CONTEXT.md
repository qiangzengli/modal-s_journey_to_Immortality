# 逆命录领域词汇

- **区域（Region）**：独立且有边界的地图空间。修为达到要求即可直接传送，不经过中间区域、不推进旬数；落地后在本图步行。
- **地点（Site）**：区域内的可交互地图位置，如渡口、矿脉、灵枢。到达后才由玩家确认行动。
- **实证（Evidence）**：货单、水样、矿纹等由规则行动记录的事实，引用真实事件 ID；聊天不是实证。
- **章节（Chapter）**：展示调查进度的手记单元，不是强制线性关卡。
- **卷结局（Campaign ending）**：玩家对万息灵枢作出的唯一选择。互斥、持久；人物不能替选。
- **余波（Aftermath）**：结局后的生计、救治与留史，由人物 Agent 使用自有资产自主决定。
- **灵矿（Ore）**：赤砂矿场的有限资源，用于炼丹、修闸、开府与部分结局；不同于货币灵石。
- **机缘（Opportunity）**：可争夺的原筑基丹。其归属独立于归脉丹和卷结局，不因新章节而重置。
- **归脉丹（Alternate pill）**：调查后炼制的一次性替代筑基机缘，服用不修改原丹归属或旧债。
- **委托（Commission）**：NPC 自主提出且提前托管报酬的灵草交换；接受、交付与失效按规则结算。
- **人物能力（Capability）**：当前资源和事实允许的白名单动作；模型选择能力，规则重新校验后执行。
- **基础攻击力（Base attack）**：当前境界下、未计装备与招式加成的攻击属性，作为普攻和剑诀的威力基础。
- **基础法力（Base spell power）**：当前境界下的法术强度，作为法术伤害和回春术的基础；施法不会消耗此属性。避免与真气混用。
- **真气（Mana）**：斗法中消耗和恢复的施法资源，每次开战补满；不决定法术强度。
- **招式威力（Ability power）**：基础属性加功法与适用兵器加成后的数值。伤害仍需结算防御、守势与波动，治疗不超过缺失气血。
- **门派（Sect）**：拥有门规、修行方向与门人的组织。同一修士同时只归属一个门派，未入门者为散修。
- **道统阵营（Alignment）**：门派所属的正道或魔道立场，不是个人善恶分数，也不等同于必然敌友关系。散修不自动归入任一阵营。
- **接引（Admission）**：接引人对拜帖作出的邀请、婉拒或暂缓决定；收到邀请后，仍须申请人明确接受才正式入门。

- **第一卷（Volume）**：新开局的七玄问道经历，独立保存在 `volume`；旧档没有此字段，继续原旅途。
- **剧情经历（Volume step）**：玩家在对应区域明确执行的一次行动；依赖其他经历的事件 ID，聊天和 NPC 决策不能代替完成。
- **剧情交锋**：第一卷中明确显示气血代价的叙事结算，和开放世界的回合斗法不同。
- **剧情信物**：随主线取得并持久保管的遗书、宝玉、升仙令和丹方；不具备通用消耗或装备操作。

- **房间（Room）**：建筑真实门洞、墙与家具围出的可行走区域；与地图共用坐标，进入时揭顶，离开时恢复。室内地点不能隔墙交互。
- **原著宗门资料**：门派、山门、人物名称和出身来自原著资料；Agent 交谈、拜帖流程、地图布局与传送门槛是游戏适配，不作为原著情节事实。见 `docs/SECT_CANON.md`。
- **审阅服务故障**：模型计费、权限或连接等失败，区别于接引人返回的暂缓/拒绝；保持待审且不生成虚构的接引事件。
