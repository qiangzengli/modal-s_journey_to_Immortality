# 故事节奏与经历深化

本次目标：扩充七玄门至筑基拜师的游玩过程，让准备、调查、人物交涉和修炼具有过程；完成后部署到服务器 `/niminglu/`，同步现有 OpenAI 配置并保留存档。

## 体验约束

- 原著人物、门派与地点不变。新增的具体任务、选择收益和耗时是游戏化编排，不冒充原著原文。
- 不增加行动点，不以现实倒计时或重复刷同一按钮拖慢进度。
- 关键经历先展示场景、已知处境、可选做法和准确代价，再由玩家确认；允许离开准备，不能在取消后扣资源。
- NPC 的实际对话继续由 Agent 生成。经历选择留在存档和相关人物记忆中，模型可以回应玩家的做法；模型不得直接发奖、完成主线或跳过战斗。
- 正常新档增加二十个阶段性节点；已越过对应节点的旧档记录为「旧历衔接」，不拉回重做，不补发资源，不虚构历史事件。
- 正在斗法、已经胜利等待取袋的旧档也必须能继续结算。

## 时间、选择与兼容

修炼节点明确显示消耗的旬数，确认后一次性结算这段游戏时间。灵圃、自然恢复和已有委托时限按现有规则正常运行；这段时间不生成虚假的 NPC 自主行动。境界在实际修炼节点提升，旧档的既有境界不下降。

选择在确定的剧情结果内影响花费时间、相关人物信任和对话记忆，不另开杜撰主线。所有路径都能通关。战斗和战利品仍按既有规则执行；新剧情不代替墨大夫、金光上人、劫修或墨蛟的真实对阵。
