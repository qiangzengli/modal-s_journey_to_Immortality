资料核对：小说章节所收录的《凡人必备手册》[宗门篇](https://www.webnovel.com/book/22305390000123802/9734063464188185)、[次要人物篇](https://www.webnovel.com/book/22305390000123802/9734063195752695)、[地理篇](https://www.readnovel.com/chapter/22305390000123802/9734063480965401)。资料用于核对专名及人物归属；没有复制原著段落。

黄枫谷使用太岳山脉和百药园。其余未核实的具体山名、殿名不补造，“某宗大殿 / 客舍”仅指可进入的通用建筑，不主张是原著中的专名地点。三维布局、家具、颜色、拜帖邀请流程、传送门槛与 Agent 性格参数为沙盒玩法适配。人物在小说中发生的后续事件不会因资料更新而自动写入本局。

“正道”筛选沿用已有玩法，用于区分越国七派一侧与魔道六宗，不等同于天南正道盟。尚未添加其余越国宗门或魔道宗门，不将沙盒中的沈秋、白芷等人物编入原著宗门。原五图的沙盒支线、散修、物品和结果不在此次宗门替换中重写。

迁移保持所有区域、人物、门派 ID，保留申请状态、获邀资格、资源、事件 ID 与剧情进度。一次性更新四名人物的静态身份和过时的初始执念，历史记录只替换相关旧专名，玩家写下的原始拜师缘由和聊天输入保留。`sects.catalogVersion=1` 防止后续读档覆盖 Agent 新形成的目标。已发出的历史拜帖决定沿用，不借迁移批准新拜帖。

黄枫谷主线中，钟灵道仍负责门务接洽；李化元作为独立人物带领禁地试炼，并在韩立筑基后收徒。坊市人物与禁地人物也已接入原著身份；自由委托和交易属于游戏分支。
