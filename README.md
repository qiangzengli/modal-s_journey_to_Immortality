# 逆命录 · 七玄问道

从七玄门入门、拜师墨大夫与发现小绿瓶开始，沿主线走向墨府和太南小会。人物交谈、AI 决策、任务、装备、斗法、灵圃、宗门与开放世界游历都在同一款游戏中，使用同一份存档。

## 启动游戏

需要 Node.js 22.9 或更新版本。直接在项目根目录运行：

```sh
npm ci
npm start
```

打开 **http://127.0.0.1:4177** 即进入游戏。无需进入子目录、选择试玩版本或另开剧情页面。旧 `/mvp/` 地址会返回同一首页。

首次配置模型时，将 `.env.example` 复制为 `.env.local`，填入 `LLM_API_KEY`。所有模型调用固定使用 DeepSeek `deepseek-v4-flash`，不调用本机模型。已有配置会继续读取，密钥不会提交到仓库或发送给浏览器。

游戏自动保存。更新保留已有进度；新安装从七玄门开局。「重开此局」会在确认后覆盖当前存档。需要额外存档时可通过 `SAVE_PATH` 指定路径：

```sh
PORT=4178 SAVE_PATH=/tmp/niminglu-another-save.json npm start
```

## 开发与验证

```sh
npm test
```

- `index.html`：唯一游戏首页。
- `server.js`：项目启动入口。
- `game/`：游戏规则、前端、模型交互及测试源码。
- `.env.local`、`.data/save.json`：本地配置和新安装的默认存档，均被 Git 忽略。
- [游戏指南](docs/GAME_GUIDE.md)：操作、模型设置、功能边界及升级存档说明。
- [领域词汇](game/CONTEXT.md)：剧情、规则与状态语义。

测试使用独立临时存档。DOM 与场景结构测试不替代真实浏览器的画面和触控验收。


剧情与修行采用《凡人修仙传》设定。主流程从七玄门经神手谷、墨府、太南小会，接入黄枫谷门籍、百药园潜修、血色禁地采药、筑基与拜师李化元。坊市取丹仍由 DeepSeek 根据局势设计多种可执行方案；禁地交药则提供另一枚筑基丹。交易和委托属于玩家可改变的自由分支。

当前可玩主线终点为筑基拜师，获得青元剑诀。境界词表覆盖炼气十三层、筑基至大乘及渡劫飞升；更高境界仅定义术语，尚无对应可玩章节。墨蛟交锋为真实回合斗法，南宫婉每回合协战，获胜并收取天灵果后才能继续交药主线。

旧存档保留人物 ID、物品、债务、历史事件与旧游历结算余额；公开身份升级为原著人物，新的黄枫谷经历单独记录，读档不会重发奖励。持有升仙令可直接入谷；没有升仙令的旧旅人可通过现有拜帖邀请入谷后登记，已有其他门籍者需自行处理退门。旧游历行动不再作为当前主线开放。

七玄门的金光上人与太南小会后的青纹道士、胡萍姑使用真实回合战斗。先调查与整备，再交战；击败并收取战利品后推进主线。金刚护罩、功法、疗伤、撤退、战败和中途存档都按战斗规则结算。已完成旧版开篇的存档保留进度，不强迫重打或重发奖励。
